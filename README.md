# AniVerse Starter Website

A beginner-friendly static anime discovery catalog built with HTML, CSS and JavaScript.

## Run it on your computer
1. Extract `aniverse-starter.zip`.
2. Open the `aniverse-starter` folder.
3. Double-click `index.html` to open it in your browser.
4. Search titles and click genre filters to test the demo.

## Customize
- Edit the anime list in `script.js`.
- Replace demo entries with titles, text, and artwork you have permission to publish.
- Add a licensed official viewing URL in each item's `watchUrl` field to enable its official watch link.
- Change colors, fonts, and layout in `style.css`.
- Change the website title and text in `index.html`.

## Important
This is a front-end demo, not a streaming server or admin uploader. It does not host video files, user accounts, or ads. Before streaming or monetizing content, obtain the necessary rights and use hosting and ad services whose terms permit your intended use. The sample titles and decorative poster art are illustrative.
